# AB Aditta

Сайт производства автомобильных ковриков EVA. Ставрополь, отгрузка по России.

Главный экран — scroll-driven video: одно непрерывное видео производственной цепочки,
привязанное к позиции скролла. Листаешь вниз — видео идёт вперёд, вверх — назад.

## Структура

```
adittaprof/
├── index.html              весь сайт: разметка, стили и скрипты в одном файле
└── assets/
    ├── video/
    │   ├── film.mp4        склеенное видео 5 этапов производства
    │   └── poster.jpg      первый кадр, показывается пока видео грузится
    └── frames/             опорные кадры этапов
```

## Как открыть локально

Просто откройте `index.html` в браузере — сборка не нужна.

Если видео не проигрывается при открытии файла напрямую, запустите локальный сервер:

```bash
npx serve .
```

## Как опубликовать бесплатно на GitHub Pages

1. Залейте содержимое папки в репозиторий на GitHub
2. Настройки репозитория → **Settings** → **Pages**
3. В блоке **Build and deployment** выберите Source: **Deploy from a branch**
4. Branch: `main`, папка `/ (root)` → **Save**
5. Через пару минут сайт будет доступен по адресу
   `https://<ваш-username>.github.io/<название-репозитория>/`
